# igui

## Правила работы

При работе с приложением обязательно следуй инструкциям [IDLE.md](IDLE.md).

- Команды Cargo выполнять из каталога `igui`; проверять только затронутый пакет.
- Тесты не требуют оборудования, внешней сети и привилегий. Локальный IPC,
  процессы и временные файлы изолировать; офлайн-проверки не подтверждают
  работу на ARM-устройстве.
- Новые команды, аргументы и флаги CLI добавлять только после явного согласования.
- Линтеры и форматтеры запускать только по прямой просьбе владельца.
- Не менять SD, NOR, GPIO или питание без отдельного согласования опыта;
  команды с `sudo` на ПК выполняет владелец.
- Публиковать код, создавать удалённый репозиторий или выпуск только после
  явного разрешения владельца. Подготовка к публикации не является разрешением.

## Суть приложения

`igui` читает подготовленный каталог игр, хранит состояние навигации в RAM,
рисует меню и передаёт выбранную игру менеджеру сеанса через локальный IPC.
Общие протокол, транспорт, DRM/KMS и примитивы ввода предоставляет `imanlib`.
Библиотека подключается через Cargo Git-зависимость с точным `rev`;
обновление коммита должно сопровождаться обновлением `Cargo.lock`.
Соседние проекты, ROM и аппаратные дампы для сборки и тестов не нужны.

Модель не выполняет I/O; runtime применяет её эффекты. Рендерер получает
байты превью через адаптер и не содержит тестовые PNG или каталог.
Ресурсы `locales/` и `controls/` устанавливаются рядом с исполняемым файлом.
[Структура исходников](docs/development.md#исходники), [формат данных](docs/catalogue.md).

Предпочтения записываются только по явным действиям при разрешённой записи.
Автоматическое переключение SD между RO/RW не реализовано; не заявлять
устойчивость к отключению питания. Подробности — в [ограничениях записи](docs/runtime.md#запись-и-завершение).
