# igui

`igui` — Idle GUI: меню каталога игр для Linux. Оно показывает изображения
и сведения об играх, поддерживает поиск, фильтры, избранное и корзину.
Для запуска игр используется менеджер сеанса
[iman](https://github.com/idleboxed/iman); самостоятельный IGUI открывает
только диалог запуска, без эмулятора.

Протокол, транспорт и общие примитивы дисплея и ввода предоставляет
[imanlib](https://github.com/idleboxed/imanlib).
Игры, BIOS, RetroArch и ядра libretro в IGUI не входят.

## Быстрый запуск

Подготовьте каталог с помощью [icat](https://github.com/idleboxed/icat)
и запустите установленное меню:

```sh
igui --games /absolute/path/to/games
```

D-pad / стрелки перемещают выделение; A / Enter подтверждает, Start запускает
игру, B меняет избранное. Для запуска игр используйте комплект с iman.
[Сборка, установка и управление](docs/runtime.md).

## Данные и ограничения

Избранное и корзина сохраняются по явным действиям пользователя.
Корзина скрывает игры, но не удаляет ROM. IGUI не переключает SD между RO/RW
и не гарантирует сохранность данных при отключении питания.
