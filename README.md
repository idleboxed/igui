# igui

`igui` — Idle GUI: меню каталога игр для Linux. Оно показывает изображения
и сведения об играх, поддерживает поиск, фильтры, избранное и корзину.
Для запуска игр используется менеджер сеанса
[iman](https://github.com/idleboxed/iman); самостоятельный IGUI открывает
только диалог запуска, без эмулятора.

Протокол, транспорт и общие примитивы дисплея и ввода предоставляет
[imanlib](https://github.com/idleboxed/imanlib).
Игры, BIOS, RetroArch и ядра libretro в IGUI не входят.

## Требования и сборка

Нужны Linux, Rust 1.85 или новее, Cargo и `date`.
Для оконного режима также нужны C-компилятор и X11/XWayland;
для DRM — доступный DRM/KMS. Локальный IPC использует tmpfs.

Cargo получает imanlib из Git-репозитория; точный коммит закреплён в
[`Cargo.toml`](Cargo.toml) и [`Cargo.lock`](Cargo.lock).
При первой сборке требуется доступ к GitHub и реестру зависимостей.
После их загрузки возможна офлайн-сборка.

Из каталога `igui` соберите оконный вариант:

```sh
cargo build --locked --release
```

Результат — `target/release/igui`. Эта команда не собирает iman или эмуляторы
и не подготавливает игровой каталог.
[Сборка для RK3032 и запуск через DRM](docs/runtime.md#сборка-для-rk3032).

## Быстрый запуск

Поместите бинарник и ресурсы в один каталог:

```sh
mkdir -p out/system/igui
cp target/release/igui out/system/igui/
cp -R locales controls out/system/igui/
./out/system/igui/igui --games /absolute/path/to/games
```

`--games` указывает каталог с готовым `catalogue.json`.
IGUI не импортирует ROM и не сканирует игры вместо индекса.
[Формат каталога и настроек](docs/catalogue.md).

`locales/` и `controls/` читаются рядом с исполняемым файлом.
При обновлении не смешивайте прежние и новые копии одного профиля в `controls/`:
дубли отключают соответствующий способ ввода.
Русский интерфейс выбирается полем `"lang": "ru"` в `prefs.json`;
без настроек используется английский.
Справка по параметрам:

```sh
./out/system/igui/igui --help
```

Для запуска игр подготовьте комплект с iman:

```text
ROOT/
├── system/
│   ├── iman/{iman,iman.json,emulation.json}
│   ├── igui/{igui,locales/,controls/}
│   └── retroarch/{retroarch,cores/,padconf/}
├── games/{catalogue.json,images/,thumbs/,states/,saves/}
└── prefs.json
```

Запускайте `system/iman/iman`: менеджер откроет IGUI и вернёт меню после игры.
Настройка эмуляторов описана в
[документации iman](https://github.com/idleboxed/iman#быстрый-запуск).
[Другие режимы запуска](docs/runtime.md).

## Управление

- D-pad / стрелки — перемещение; A / Enter — подтверждение.
- Start — запуск выделенной игры, в том числе из результатов поиска.
- B — избранное; Y — верхние фильтры; X — нижние фильтры.
- Select / Delete — корзина с подтверждением A и отменой B;
  в корзине — восстановление игры.
- Esc — закрытие окна на ПК; выход из шапки — завершение сеанса.

Поиск и фильтры применяются совместно. Корзина скрывает игры из обычного списка,
но не удаляет ROM. [Навигация и профили геймпадов](docs/runtime.md#управление-и-навигация).

## Features

- `desktop` — включена по умолчанию; окно X11.
- `rgb565` — включена по умолчанию; DRM-буферы RGB565 вместо XRGB8888.
- `drm` — вывод через Linux DRM/KMS без оконной системы.
- `drm-diagnostics` — измерения операций DRM/KMS.

## Данные и ограничения

Предпочтения находятся в `prefs.json` рядом с `games/`.
Избранное и корзина сохраняются по действиям пользователя.
При запуске игры через iman сохраняется выбранная позиция, если запись разрешена.
Навигация и выход не сохраняют настройки.

**IGUI не меняет режим монтирования SD и не гарантирует сохранность данных
при отключении питания.** Игровые сохранения обрабатывает эмулятор,
а не IGUI. [Сохранение предпочтений](docs/runtime.md#запись-и-завершение).

## Исходники

- [`runtime`](src/runtime/mod.rs) — запуск, цикл меню и передача игры менеджеру.
- [`model`](src/model/mod.rs) — каталог, состояние меню, поиск и фильтры.
- [`render`](src/render/mod.rs) — панели, превью и диалоги.
- [`storage`](src/storage/mod.rs) — чтение данных, предпочтения и снимки экрана.
- [`input`](src/input/mod.rs) — геймпады и правила навигации.
- [`display`](src/display/mod.rs) — оконный и DRM-вывод.
- [`ipc`](src/ipc/mod.rs) — команды локального IPC.

## Проверки

Проверки в [`tests/`](tests/) сгруппированы по компонентам исходников:
модель, отрисовка, ввод, IPC, runtime и хранение данных. Общий вход —
[`main.rs`](tests/main.rs), помощники — [`common/`](tests/common/),
данные — [`_fixtures/`](tests/_fixtures/).
Из каталога `igui` для выбора компонента используйте фильтр имени, например:

```sh
cargo test --locked --test integration input::
```

Из каталога `igui`:

```sh
cargo test --locked -- --test-threads=1
cargo test --locked --all-features -- --test-threads=1
cargo check --locked --no-default-features --all-targets
```

Тестам нужны доступный для записи `/dev/shm` и временный каталог.
Оборудование, игры и соседние приложения не требуются.
[GitHub Actions](.github/workflows/rust-package.yml) также проверяет компиляцию
для ARMv7 musl. Тесты на ПК не подтверждают работу на конкретном устройстве.
