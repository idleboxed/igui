# Каталог и ресурсы

IGUI читает готовый каталог игр и локальные ресурсы.
Импорт ROM и подготовку метаданных выполняйте отдельно.
Доступность выбранной игры перед запуском проверяет менеджер сеанса.

## Расположение

```text
ROOT/
├── prefs.json
├── games/
│   ├── catalogue.json
│   ├── images/<platform>/<hash[0:2]>/<original-name>
│   └── thumbs/<hash[0:2]>/<hash>.png
└── system/igui/
    ├── igui
    ├── locales/ru.json
    └── controls/*.json
```

`--games` задаёт каталог с `catalogue.json`, не сам JSON или устройство.
При запуске через iman каталог `games/` задаёт менеджер.
`prefs.json` находится в родительском каталоге `games/`.

## catalogue.json

Пример вымышленной записи; хэш ниже не относится к реальному ROM:

```json
{
  "games": [
    {
      "hash": "d8d0f5b64cbd7b44e42e338a4d6cddcc93a5576c42d0e6d2d89f245da9a267ca",
      "platform": "MD",
      "image": "MD/d8/Amber Quest.md",
      "title": "Amber Quest",
      "region": ["USA"],
      "year": 1991,
      "players": 2,
      "genre": "Platformer",
      "description": "A synthetic adventure.\n\nNo ROM is included."
    }
  ]
}
```

- Обязательны `games` и четыре поля каждой записи: `hash`, `platform`, `image`, `title`.
- Неизвестные ключи игнорируются. Лимит JSON — 16 МиБ.
- `hash` — уникальные 64 строчных hex-символа. Для одиночного ROM это SHA-256
  его точных байтов, вычисленный на ПК. IGUI не пересчитывает контрольные суммы.
- `image` — относительный POSIX-путь внутри `images/`, до 512 байт UTF-8;
  компоненты до 255 байт. Абсолютные пути, `.`/`..`, пустые компоненты, обратная
  косая черта и непереносимые символы запрещены. Полные пути уникальны без учёта регистра.
- `platform` — от одного до шести ASCII-символов `A`–`Z` или цифр.
  Для запуска нужен соответствующий эмулятор и его настройка в iman.
- `title` — непустая строка без управляющих символов.
- `year` — `1..9999`, `players` — `1..255`; отсутствие или `null` означают неизвестное значение.
- `genre` — непустая строка без управляющих символов. Хранится английское название;
  UI переводит его, если в выбранном словаре есть ключ.
- `region` — `null`, отсутствие или массив строк; пустой массив означает отсутствие
  региональных ограничений. Сумма длин — до 128 байт; пустые строки, управляющие
  символы, запятая и заменители `?`, `-`, `World` запрещены.
- `description` — текст до 16 КиБ UTF-8, допускающий CR/LF/tab; CRLF нормализуется.
  Названия и описания игр словарём UI не переводятся.

Отсутствующий индекс, повреждённый JSON, неверные типы и дубли останавливают
загрузку. Исправьте каталог и перезапустите IGUI.

## Превью и переводы

Для выделенной игры читается только `thumbs/<hash[0:2]>/<hash>.png`.
При переименовании ROM хэш и превью сохраняются. PNG — RGB8, не более
640×480, файл и буфер декодирования — до 1 МиБ. Декодированная картинка
масштабируется в область карточки с сохранением пропорций.
Отсутствующая, неподдерживаемая или повреждённая картинка даёт заглушку;
другие расположения файлов не проверяются.

Английские ключи интерфейса встроены. `prefs.json.lang` выбирает один
`locales/<код>.json` рядом с исполняемым файлом, независимо от cwd и игр.
Код — две или три строчные ASCII-буквы. Файл до 64 КиБ содержит объект
`"English key": "Translation"` с непустыми однострочными значениями.
Нет ключа — показывается английский; нет/неверен словарь или язык — встроенный EN.
Русский словарь поставляется в [`locales/ru.json`](../locales/ru.json).
Чтобы сменить язык, измените `lang` в `prefs.json` и перезапустите IGUI.

## prefs.json

```json
{
  "favourites": [],
  "trash": [],
  "current_item": "d8d0f5b64cbd7b44e42e338a4d6cddcc93a5576c42d0e6d2d89f245da9a267ca",
  "lang": "ru"
}
```

Нет файла — пустые отметки и EN, без создания файла при загрузке.
В существующем JSON `favourites` обязателен, `trash` необязателен:
оба — массивы SHA-256. Некорректный JSON или отметки останавливают запуск,
а не сбрасывают настройки. Лимит файла — 1 МиБ. Неизвестные ключи сохраняются.
Дубли отметок сворачиваются в памяти; хэши отсутствующих игр не удаляются.

Корзина — только отметки, не удаление ROM или PNG. Порядок сохраняется от
последнего удаления к первому; восстановленная и вновь удалённая игра попадает наверх.
`current_item` хранит выбранный каталожный хэш после явной команды игрового запуска.
Совпадающее значение не переписывает файл. Неверный или отсутствующий хэш
оставляет обычный начальный выбор. Состояние от iman имеет приоритет после возврата из игры.

Новые отметки избранного и корзины появляются только после успешной записи.
Не редактируйте `prefs.json` во время работы IGUI: обнаруженная внешняя правка
блокирует сохранение. Чужой или оставшийся `.prefs.json.tmp` не перезаписывается.
При ошибке сохранения проверьте файлы и перезапустите IGUI.
Ошибка после записи не обязательно означает, что файл остался прежним.
[Когда сохраняются предпочтения](runtime.md#запись-и-завершение).
